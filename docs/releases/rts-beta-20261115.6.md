# RTS gangster beta 0.2.0-beta.2 — Illustrated 3D

## Windows installation

Download **RTS-gangster-beta-Setup.exe** to install the game. Close the game
before running the installer. **RTS-gangster-beta-Portable.exe** is the optional
version that runs without installation. The automatic source-code archives are
for development.

New profiles select **Illustrated 3D** automatically. If an older profile keeps
another style, open **Book → Options → City artwork → Illustrated 3D**, save,
and reopen the city. Existing saves continue to use the same save folder.

## Included in this build

- Painted brick, limestone, stucco and shopfront textures on the 3D buildings.
- 50 civilian clothing combinations, eight occupational uniforms, eight body
  builds, three heights and ten skin shades on animated 3D characters.
- 32 face presets and 18 hair and headwear variants. Appearance is stable
  between saves and uses shared bodies, textures and a bounded geometry cache.
- Painted coupe, delivery-truck and sports-car models in twelve period colours.
  Paint stays with fleet vehicles when drivers change. Tyres, glazing, chrome,
  roofs and canvas keep their own materials.
- Uncovered bodies keep the victim's 3D wardrobe and build after the fall;
  police covering and the coroner's collection continue to work.
- Includes the existing RTS clock, live City Plan, movement controls, minimap,
  Organizer access and continuous weekly financial settlement.

## Verification and current limits

The relevant vehicle, traffic, character reuse and loading checks pass, and
the actual renderer was used to inspect all 36 car/paint combinations and all
50 civilian outfits. Windows executables are produced by the GitHub Windows
build workflow from the tagged source commit.

This remains beta artwork. Clothing extensions, fur collars and some UV seams
still need refinement; church and roof materials retain procedural artwork.
Light graphics and Standard textures remain available for slower computers.
