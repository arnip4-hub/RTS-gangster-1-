# RTS gangster beta — 0.2.0-beta.4 clothing hotfix

This hotfix corrects a severe illustrated-3D rendering problem where generated
coats and dresses could use incompatible inverse-bind data and stretch into
long triangles during character animation. Garment shells now follow the
character pelvis safely while the source body continues to provide animation.

The Windows package retains the existing save location and all beta.4 police,
FBI, court, transport and RTS clock features.
