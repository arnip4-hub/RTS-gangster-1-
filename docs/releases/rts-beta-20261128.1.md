# RTS Gangster 1 — Beta 0.3.0-beta.12

Release candidate prepared 28 November 2026. Planned tag: `rts-beta-20261128.1`. This is a new prerelease, not an in-place replacement of beta.11. The gameplay baseline is commit `ea192c4` on `rts-development`.

## Live city and crew commands

- The Hoods bar offers Enter building. Hoods remain inside owned premises until recalled or cancelled; interrupted work can resume through the door.
- Selected car occupants park and dismount before walking to the entrance. Commands revalidate premises and handle lost or destroyed buildings.
- Indoor stays survive saving, loading and weekly settlement. City-plan group selection and command dispatch are covered by regression tests.
- Crew planning and street detail have been improved.

## Organizer and finances

- All live Organizer sections use the overhead Book layout, with consistent selection centering and navigation.
- The crew skill reference includes armed alternatives.
- Live purchases require a lieutenant at gang premises; invalid purchases do not charge cash. Financial regression coverage verifies successful purchases and avoids double-counting vehicle assets.

## Rendering

- Corrected undefined negative-base exponentiation in the road shader.
- Retains the single painted 1930s 3D city renderer and the beta.11 wardrobe, vehicle, building and night-lighting improvements.

## Validation

The gameplay baseline records 201 passing tests across 18 affected suites, a passing production build and save-schema check, and Chromium/SwiftShader day/night rendering without browser or shader errors. Live Book, crew skill columns and Enter building were checked in the browser. These targeted checks do not clear previously reported broader-suite baseline failures or establish physical-GPU compatibility.

The Windows workflow preserves the previous regression gates and adds live building, movement, vehicle navigation/choice, asset wealth, finance, city-plan and rendering architecture tests. It verifies the package and lockfile versions and both exact executable filenames. The workflow does not publish automatically on a push.

## Windows files

- `RTS-gangster-beta-Setup-0.3.0-beta.12.exe` — installer.
- `RTS-gangster-beta-Portable-0.3.0-beta.12.exe` — portable executable.

## Release procedure

1. On GitHub Actions, run **Windows beta build and tests** on `rts-development` with the tag blank.
2. Download the `rts-gangster-beta-windows` artifact. On Windows, install and launch Setup, launch Portable separately, start a game, check street and Book views, Enter building, vehicle arrival, purchasing and save/reload. Check that an existing beta.11 save loads (back up saves first).
3. Record the successful smoke test and tested commit. If the branch has changed, repeat the artifact-only build and smoke test for the new head.
4. Dispatch the same workflow on the tested branch head with tag `rts-beta-20261128.1`. It rebuilds and creates a new prerelease; it refuses to overwrite an existing release or tag.
5. Verify the release contains both EXEs, then update the README download links to:
   - https://github.com/arnip4-hub/RTS-gangster-1-/releases/download/rts-beta-20261128.1/RTS-gangster-beta-Setup-0.3.0-beta.12.exe
   - https://github.com/arnip4-hub/RTS-gangster-1-/releases/download/rts-beta-20261128.1/RTS-gangster-beta-Portable-0.3.0-beta.12.exe
   - https://github.com/arnip4-hub/RTS-gangster-1-/releases/tag/rts-beta-20261128.1

Windows packaging and manual Windows smoke testing are not yet confirmed at preparation time. GitHub Pages deployment is separate and does not verify Windows packaging.
