# RTS Gangster 1 — Beta 0.3.0-beta.11 (updated 24 November 2026)

This is an **in-place rebuild of the existing beta.11 release** from the current `rts-development` branch. It replaces the installer and portable executables under their existing filenames; no duplicate release is necessary.

## One painted 3D city, not multiple graphics paths

- Selected **one illustrated, painted 1930s 3D style** for the city. Legacy `detailed`, 2D illustrated, and old experimental preferences migrate to that single renderer.
- Retired the 2D illustrated world-sprite runtime path. Historic artwork and earlier experiments remain preserved in source history and the separate art archive.
- Kept 2D portraits, interface imagery and painted textures for actual 3D models.
- Retained the 3D skinned wardrobe, body morphology, hair and headwear for city characters.

## Vehicles, people and street fixes

- Added period enamel vehicle colours and variants, improved vehicle roll and fittings, and updated police vehicle livery.
- Corrected generated garments, bind-space transforms, actor height normalization, and `Spine`/upper-body weight selection on larger bodies.
- Kept 3D street corpses visible in the unified renderer and fixed premature corpse sheets.
- Corrected the truck canvas and police door band.

## More convincing 1930s streets

- Improved building massing with L/U wings, courtyards, corner pavilions, rear annexes and larger commercial buildings.
- Added mansard roofs, skylights, marquees, blade signs, pilasters and stoops.
- Added **13 storefront styles** and **12 facade palettes** with improved materials and night-lighted assets.
- Fixed the avenue asphalt appearance.

## RTS and interface changes retained from earlier beta.11 updates

- Building property information and context-sensitive job dispatch, alongside the original-style top-bar shortcuts and Options.
- Opening the job book now selects the planner map, hides redundant organizer tabs and uses a compact vertical map toolbar.
- Police custody, independent scene investigations and live-time case handling improvements already merged into RTS.
- Hoods commands, wardrobe persistence, and Windows branding remain part of the standard game.

## Checks and packaging

The Windows release workflow installs the locked dependencies, runs focused RTS, police, business, UI, character and rendering regression tests **plus focused 3D vehicle, storefront, city-layout and rendering tests**, verifies the `0.3.0-beta.11` version and builds the application before publishing. Renderer and industrial regression fixtures have also been updated for the expanded building catalogue and storefront pools. The full suite is not part of the focused Windows packaging gate.

The release provides two Windows files:

- `RTS-gangster-beta-Setup-0.3.0-beta.11.exe`: Windows installer.
- `RTS-gangster-beta-Portable-0.3.0-beta.11.exe`: portable version without installation.

**Beta notice:** Visual and gameplay issues can still occur; report them with the in-game debug export. The separate GitHub Pages deployment is not a prerequisite for the Windows release.
