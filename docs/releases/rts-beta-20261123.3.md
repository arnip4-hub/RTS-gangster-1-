# RTS Gangster 1 — Beta 0.3.0-beta.11

This release integrates the user-tested **Illustrated 3D** experimental character and wardrobe system into the normal RTS beta, with both Windows packaging options. It is the successor to 0.3.0-beta.10.

## Illustrated 3D city artwork

- **Options → City artwork → Illustrated 3D (experimental)** now selects and persists the 3D mode instead of silently falling back to Detailed.
- Save your game and reopen the city to activate the selected artwork.
- Animated GLB character rigs receive generated, skeleton-skinned coats, robes and dresses; headwear follows its head anchor.
- Wardrobe meshes are fitted and weighted in the original GLB bind space to avoid unstable animation inverses and stretched geometry.
- Body proportions and shoulders are adjusted against bind-pose reference data, without patching bone `updateMatrix` functions.
- Removes body and garment fragment clipping that previously made large holes in moving characters.
- Existing Detailed and Illustrated 1930s modes remain available.

## Verification

- TypeScript check, focused character morphology and wardrobe skinning tests, UI preference tests, and existing police, building and UI release regressions run before Windows packaging.
- Wardrobe gallery captures cover different character types and walk phases in a separate workflow.
- The experimental 3D mode was tested manually in a portable Windows preview before the release.
- The broader full-suite regression workflow is separate; the beta status reflects continuing testing.

- `RTS-gangster-beta-Setup-0.3.0-beta.11.exe` — Windows installer or upgrade.
- `RTS-gangster-beta-Portable-0.3.0-beta.11.exe` — Portable Windows executable that runs without installation.

**Beta notice:** Illustrated 3D remains experimental. Report visually stretched clothing, unusual poses or missing wardrobe parts with an in-game debug file.
