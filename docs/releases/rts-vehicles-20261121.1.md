# RTS gangster beta — 0.3.0-beta.7

## Illustrated 1930s vehicle fleet

All six new vehicle designs are included in **Illustrated 1930s (preview)**,
with eight directional views each (48 frames):

- Forest-green sedan.
- Slate-blue pickup.
- Burgundy coupe with an ivory roof, used for the speedster vehicle type.
- Cream delivery truck for goods deliveries.
- Black-and-ivory police car.
- Unmarked dark FBI sedan.

Police and FBI appearances follow the driver's role. The closed-roof coupe
hides the seated driver used by the open 3D car. Vehicle movement, simulation
rules and save formats are unchanged; existing saves remain compatible.

Select **Options → Illustrated 1930s (preview)**, save and reopen the city to
apply the style. Other visual styles retain their existing vehicle presentation.
This remains preview artwork; individual angles may need further refinement.

## Windows downloads (64-bit)

- **RTS-gangster-beta-Setup-0.3.0-beta.7.exe** — installer with a choice of installation folder.
- **RTS-gangster-beta-Portable-0.3.0-beta.7.exe** — run without installing.

Both packages contain the same game and all six vehicle designs.
