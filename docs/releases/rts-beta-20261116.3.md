# RTS gangster beta — 0.2.0-beta.5

The original 1.0.8 wide avenue treatment is restored in the RTS city: planted
14 m central medians, tram beds, tree rows, kerbs, lamps, and dashed lane marks.
The existing city layout and tram simulation stay in place.

Wardrobe meshes now remain in the normalized actor coordinate frame and follow
their attached skeleton bone relative to its rest pose. This avoids baking the
source rig's inverse scale into garment vertices, which can magnify geometry
precision errors on some graphics drivers.

This build is intended to check the character stretching reported on Windows
with Intel Iris Xe graphics. The Linux render review shows all 58 wardrobe and
uniform combinations through the walk cycle; the Windows driver issue still
needs confirmation on the affected system.
