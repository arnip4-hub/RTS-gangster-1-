# RTS Gangster 1 — Beta 0.3.0-beta.8

## Hoods and direct city control

- Fully revised Hoods command bar with eight visible slots, paging, crew/pool selection, Ctrl/Cmd multiselect, Shift-range selection and status labels.
- Street actions: **Move, Guard, Patrol, Tail, Kill, Assault, Flee/HQ and Stop**, using the existing live street-order system.
- **Guard** holds a selected position; **Patrol** follows a two-way route, and both orders survive saving and loading.
- Click a known building and choose **Send hoods / crew here** to select a command and individual people, a whole crew or pool members. Review and confirm before dispatching.
- Orders target the building's actual street entrance, and the building can remain selected while dispatched people are highlighted in Hoods.
- RTS runs independently on `rts-development`; no legacy Original Gangster branch is required.

## Windows app and setup

- Dedicated RTS Gangster 1 application icon and matching installer/uninstaller artwork.
- **Setup** installer and **Portable** executable for Windows (64-bit).

## Illustrated 1930s vehicle artwork (preview)

Preserves the six already released vehicles from beta.7: sedan, pickup, coupe, delivery truck, police car and unmarked FBI car, with eight views per vehicle. The vehicles are part of the **Illustrated 1930s (preview)** style. The separate experimental Illustrated 3D work is not activated, and the ongoing `graphics/illustrated-vehicles` development branch remains untouched.

## Compatibility and testing

- Existing saved games and app installation identity are preserved.
- Live Guard/Patrol orders are now included in the validated save format.
- Automated RTS regression tests (including Hoods and building dispatch) and vehicle sprite tests run before Windows packaging.
- Experimental illustrated vehicle angles and new UI layout may still need visual polish.

## Downloads

- `RTS-gangster-beta-Setup-0.3.0-beta.8.exe` — install or upgrade the game.
- `RTS-gangster-beta-Portable-0.3.0-beta.8.exe` — run without installation.
